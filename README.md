# 🩺 Health Screening AI

A voice-based health screening web application that conducts a basic conversational health intake, captures user responses through speech, and generates a structured screening summary.

> ⚠️ **Disclaimer:** This application is designed for basic health screening/intake only. It does not provide medical diagnosis, prescriptions, or definitive medical conclusions.
